# Security Policy

This repository contains static analysis queries. They don't run in your application, so false positives and missed
vulnerabilities are regular bugs: please report them as [issues](https://github.com/openapistack/openapi-backend-codeql/issues/new/choose).

**Found a vulnerability in openapi-backend itself?** Report it privately through
[openapi-backend's security advisories](https://github.com/openapistack/openapi-backend/security/advisories/new).
Its [SECURITY.md](https://github.com/openapistack/openapi-backend/blob/main/SECURITY.md) and
[threat model](https://github.com/openapistack/openapi-backend/blob/main/docs/threat-model.md) explain what counts.

**Found a problem with this repository's release pipeline or packs** (for example a tampered pack on GHCR)? Report
it privately through [this repository's security advisories](https://github.com/openapistack/openapi-backend-codeql/security/advisories/new),
or email **support@openapistack.co** with `SECURITY` in the subject line.
